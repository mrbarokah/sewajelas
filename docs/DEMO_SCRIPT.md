# Suggested demo script — 3 minutes

Editorial recommendation, **not** a verified organizer duration limit. Use real behavior and fictional personal data. Hide credentials; never present simulated answers as live Muse output.

| Time | Show | Narrative |
| --- | --- | --- |
| 0:00–0:20 | Rental problem | Cheap rent may hide water problems, fees and unclear repairs. |
| 0:20–0:35 | Current mode | Explain rehearsal scope and show Muse only after a real connection succeeds. |
| 0:35–1:15 | Interview | “Cari kontrakan di Jakarta Selatan, lima juta, sewa saja.” Show actual clarification and progress. |
| 1:15–1:50 | Improve style | Correct a long answer into one concise, polite question. Explain context guidance, not fine-tuning. |
| 1:50–2:15 | Landlord roleplay | Test unreliable water or refusal; show actual behavior. |
| 2:15–2:35 | History/export | Show retained conversation and export. Current summary is an excerpt, not verified property facts. |
| 2:35–3:00 | Next milestone | Confirmed brief, original available photos, evidence cards, authorized sources and contact consent. |

If no real API is available label the recording **Simulation / provider not demonstrated**. This honest fallback may weaken or fail a model-use requirement. UI completeness does not prove Meta integration.

If cards ship, replace roleplay with a brief and two cards; label fixtures, show cost uncertainty and useful questions. Do not demonstrate planned features as completed.
